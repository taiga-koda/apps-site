サポートプライバシーポリシーEnglish

Koda Apps（以下「運営者」）は、スマートフォンアプリ「シフかわ」（以下「本アプリ」）における情報の取り扱いについて、次のとおり定めます。

制定日: 2026年11月11日

1. 本アプリが端末内に保存する情報

メンバー名、シフト（日付・時間帯）、タイトル、お店の名前、ひとこと、テンプレートやアイコンの選択は、お使いの端末の中にのみ保存されます。運営者のサーバーへ送信されることはありません。本アプリにはアカウント登録・ログインがなく、運営者はこれらの情報を取得できません。

2. 書き出した画像

書き出した画像は、端末の一時領域に作られ、ユーザーの操作で開く共有画面へ渡されます。共有先（写真アプリ・メッセージ・SNS など）への送信はユーザーご自身の操作によるもので、運営者は関与しません。次回の書き出し時に前回の一時画像は削除されます。

3. 広告（Google AdMob）

本アプリは、プレビュー画面の下部に Google LLC の広告配信サービス「Google AdMob」によるバナー広告を表示することがあります。広告の表示にあたり、Google の広告 SDK が次のような情報を取得・送信する場合があります。

  • IP アドレス
  • アプリの起動・操作などの利用状況、診断情報（起動時間、クラッシュ、パフォーマンスなど）
  • 広告 ID などの端末識別子

本アプリは、パーソナライズされていない広告のみを要求します。ユーザーの興味関心に基づく広告のために、他社のアプリやウェブサイトをまたいでユーザーを追跡することはありません（iOS の App Tracking Transparency の許可は求めません）。

欧州経済領域・英国など、法令上同意の取得が必要な地域では、Google の同意管理の仕組み（UMP）により同意をお尋ねし、同意が得られない場合は広告を表示しません。同意内容は、プレビュー画面に表示される「広告のプライバシー設定」から後から変更できます（表示されるのは設定の変更が必要な地域のみです）。

Google による情報の取り扱いは、Google のポリシー「Google のサービスを使用するサイトやアプリから収集した情報の Google による使用」をご覧ください。端末の広告 ID は、OS の設定からリセットまたは削除できます。

4. アプリ内課金（RevenueCat）

「広告を消す」の購入状態の確認・復元のため、本アプリは購入管理サービス「RevenueCat」（RevenueCat, Inc.）を利用します。購入の際、購入履歴（購入した商品・購入日時など）と、RevenueCat が発行する匿名のユーザー ID が RevenueCat に送信されます。決済は App Store または Google Play が行い、クレジットカード番号などの支払い情報を運営者や RevenueCat が受け取ることはありません。氏名・メールアドレスなど、運営者がお客様個人を特定できる情報は取得しません。

5. 取得しない情報

本アプリは、位置情報、連絡先、写真ライブラリの内容、カメラ・マイクの情報を取得しません。また、広告と購入管理以外の解析ツールは使用していません。

6. 第三者への提供

運営者は、法令に基づく場合を除き、ユーザーの情報を第三者へ提供しません。ただし、上記 3・4 のとおり、広告配信および購入管理のために Google と RevenueCat の SDK がそれぞれの情報を取得します。

7. お子様について

本アプリは主にお店・サロンの運営者向けに作られており、13 歳未満のお子様を対象としていません。

8. データの削除

端末内のデータは、アプリ内で削除するか、アプリを削除することで消去されます。RevenueCat に保存された購入情報の削除をご希望の場合は、下記の連絡先へご連絡ください。

9. 改定

本ポリシーは、法令の変更やアプリの機能追加に伴い改定することがあります。重要な変更があるときは、このページでお知らせします。
